# inewproject-lang

Translation files for the EN | BM | 中文 language switcher on [inewproject.com](https://www.inewproject.com).
They hold the site's public page text in Bahasa Malaysia and Chinese, and nothing else.
`map/` holds the front-end files of the /map/ page (page_map_vN.js / .css), served the same way.

Served to the site through jsDelivr, pinned to a commit, so a published file never changes:
`https://cdn.jsdelivr.net/gh/yewbryan091-eng/inewproject-lang@<commit>/dict.ms_v2.js`

Do not edit these files by hand. The map files come from `inewproject.os/inewproject-2026/project/map-v2/easyasia/` (deploy/page_map_vN.*). They are generated by `translations.py` in the iNewProject workspace
(`inewproject.os/projects/site-languages/`).

## potm/ — Project of the Month (24 Oct 2026)
`np-potm_v1.js`: popup on the homepage and New Launches, plus a permanent "Project of the Month · <month>" badge on each winner's cards and listing.
It is loaded from the inewproject.com Header Scripts box via jsDelivr, pinned to a commit. The images sit next to it; the site's own copies are the fallback.
Off switch in the box: `window.NP_POTM_LIVE = false`.

## search/ v2 (25 Oct 2026): homepage + New Launches
`np-search_v2.js` + `np-search_v2.css`: the same search panel on the homepage and on New Launches (/project/), plus the
New Launches round search bar and drawing. `nl/nl-house_*.webp` = the drawing (a house with a family on its path; the
red line that runs to it is drawn by the script). Loaded with SRI by the "iNewProject . search v2" block in the admin
Header Scripts box. v1 files stay for the record (older pinned commits still use them).

## unit/ — e-Enquiry unit popup (28 Oct 2026)
`np-unit_v1.js`: the "Step 1 of 2" unit popup on every e-Enquiry page. A new left side (steps, the unit, its price, the
rooms row, layout / facing / view / row, the Enquire button); the floor plan on the right stays the site's own and is
only sized so it always fits the window. Never shows "RM 0" (also in Step 2 and the on-page receipt) or empty "—" values.
Loaded from the admin Header Scripts box via jsDelivr with SRI. Off switch: `window.NP_UNIT_LIVE = false`.
`np-unit_v1-1.js`: the steps line, its numbers and the availability pill at 14 px like all reading text; narrow phones
show "1 Unit details of 2"; room numbers stay level when a label wraps; a layout written as "null" counts as empty.
`np-unit_v1-2.js`: Step 2 ("Your details") in the same style: the steps line with step 2 on, a title, the chosen unit as a
card with "Change", the site's own form restyled (16 px fields, 14 px+ text); the form, its checks and consent wording stay
the site's own. Also: a view that only starts with the facing word ("South-Facing Commercial Frontage") is kept whole.
`np-unit_v1-3.js`: "Change" on the Step 2 unit card closes the popup (as a click outside it does), so the visitor picks
another unit from where they were on the page (same block, level and scroll); the name, phone and email they typed come
back in the next unit's form (held in the page only, never stored). "Unit details" in the steps line still goes back to step 1.

## receipt/ — e-Enquiry receipt (31 Oct 2026)
`np-receipt_v1.js`: the receipt shown after an e-Enquiry is submitted, redrawn as one document: "Enquiry received" and the
time it was submitted, the Reference ID with Copy, the enquiry (project, unit, block + level, price, layout, size, position,
view) beside the contact details, what happens next, the e-Enquiry incentive, then Save to my account (or View my
e-Enquiries) / Print / Done with the reward condition word for word. A unit with no price shows "RM -". Print opens the same
document in the visitor's language. EN / BM / 中文; the site's own receipt stays underneath as the fail-safe.
Loaded from the admin Header Scripts box via jsDelivr with SRI. Off switch: `window.NP_RECEIPT_LIVE = false`.

## ui/ — card Save buttons + header Log in / Register (29 Oct 2026)
`np-ui_v1.css`: every card's Save button shows a bookmark (filled when saved), the word at 14 px on screen, on one middle
line with the badge beside it (a small script in the box shows the bookmark alone where a card is too narrow, and under
the badge on the narrowest cards); the header's Log in / Register as a quiet link and a solid red button in sentence case,
one line on every phone. Loaded from the Header Scripts box via jsDelivr with SRI; if it fails, the site's own styles show.
