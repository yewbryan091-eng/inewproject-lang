# inewproject-lang

Translation files for the EN | BM | 中文 language switcher on [inewproject.com](https://www.inewproject.com).
They hold the site's public page text in Bahasa Malaysia and Chinese, and nothing else.
`map/` holds the front-end files of the /map/ page (page_map_vN.js / .css), served the same way.

Served to the site through jsDelivr, pinned to a commit, so a published file never changes:
`https://cdn.jsdelivr.net/gh/yewbryan091-eng/inewproject-lang@<commit>/dict.ms_v2.js`

Do not edit these files by hand. The map files come from `inewproject.os/inewproject-2026/project/map-v2/easyasia/` (deploy/page_map_vN.*). They are generated by `translations.py` in the iNewProject workspace
(`inewproject.os/projects/site-languages/`).
